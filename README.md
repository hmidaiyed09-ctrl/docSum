# 📚 DocSum

Upload your subject's documents — DocSum's AI turns them into a **step-by-step interactive course**.

Works with **any OpenAI-compatible provider** (OpenAI, OpenRouter, Groq, Ollama, LM Studio…). You configure the base URL, API key and model — nothing is hardcoded.

## Features

- **Upload page** — one centered box: drag & drop PDFs, images, TXT/Markdown, or code files, plus an optional "focus" prompt.
- **Smart PDF pipeline** — text is extracted per page with `pdf.js`; pages with **no extractable text** (scans, diagrams) are rendered to images and transcribed by your vision model. Uploaded images are auto-captioned.
- **AI course generation** — the AI receives an indexed manifest of all your material (asset 0, asset 1…) and builds a course: cover + ordered lessons.
- **Interactive lesson player** — two panels:
  - **Left**: the AI explains each step; hit **Continue** to advance, or type to **go deeper** on anything (streaming answers).
  - **Right**: the slide — your uploaded image / PDF page, an **AI-generated HTML/CSS visual** (diagrams, tables, timelines), or a **syntax-highlighted code example** with a copy button.
- **Progress ring** in the sidebar; course and progress are saved locally.

## Getting started

```bash
npm install
npm run setup   # copies the pdf.js worker into /public
npm run dev
```

Open http://localhost:3000, click the ⚙️ gear (top-right) and configure your provider:

| Field | Example |
|---|---|
| Base URL | `https://api.openai.com/v1` |
| API Key | `sk-…` (leave empty for local providers) |
| Model | `gpt-4o` |
| Vision model | optional — used for images/scanned pages |

Then drop your documents, optionally say what to focus on, and hit **Start learning**.

## Architecture

```
app/
  page.tsx                    # upload page (drag & drop + focus prompt)
  learn/page.tsx              # two-panel lesson player
  api/transcribe/route.ts     # vision: transcribe scanned pages / caption images
  api/generate-course/route.ts# AI builds the course JSON
  api/chat/route.ts           # streaming "explain deeper" chat (SSE passthrough)
lib/
  ingest.ts                   # client-side PDF text extraction + page rendering (pdf.js)
  ai-server.ts                # OpenAI-compatible client (custom base URL/key/model)
  types.ts / settings.ts / idb.ts
components/
  SlideRenderer.tsx           # cover / asset / HTML visual / code slides
  CodeBlock.tsx               # highlight.js + copy button
  Markdown.tsx / ProgressRing.tsx / SettingsModal.tsx
```

### Course JSON format (generated by the AI)

```jsonc
{
  "title": "…", "subtitle": "…",
  "cover": { "title": "…", "subtitle": "…" },
  "lessons": [
    { "title": "…", "blocks": [
      { "type": "text",  "content": "markdown narration" },
      { "type": "asset", "ref": 0, "caption": "why we look at this" },
      { "type": "html",  "html": "…", "css": "…" },
      { "type": "code",  "language": "python", "code": "…", "caption": "…" }
    ]}
  ]
}
```

## Notes & limitations

- API keys live in your browser's localStorage and are only proxied through your own Next.js API routes — this is a personal/local tool, not a multi-tenant service.
- Very large scanned PDFs consume a lot of vision calls; the manifest truncates each asset's text to ~6k chars.
- Notes sidebar button is a placeholder for a future feature.
